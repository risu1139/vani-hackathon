# Evidence for persona priors

| File | What | Grade |
|---|---|---|
| `hook_priors.json` | Opening/hook style vs meeting rate per segment (region, turnover band, category group). PS07 natural experiment, adjusted for week × trigger bucket | MODERATE for region and turnover; WEAK for category; see each row's CI |

Summary (from raw/research/2026-10-10-bot-version-segment-analysis.md):
- **Default:** the enquiry-count hook. It beats the interest hook by 0.5 points and the discovery opener by 2.5 points overall.
- **Interest hook:** better in East (+1.8) and Furniture (+3.3). Worse in North (−1.2), for 0–40 L sellers (−0.9), and for apparel, jewellery, pharma, textiles and ayurvedic (−2.7 to −3.5).
- **Discovery opener:** it is never significantly better. Avoid it for small sellers (−3.2).
- **No data** for voice gender, formality and pitch: PS07 used one voice. These are explored in Loop 2.
